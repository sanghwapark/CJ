# CTEQ-JLab collaboration downloads

Welcome to the CJ downloads page!

## PDF and Structure Function sets

Programs and grids to calculate the CJ PDFs and structure functions are collected in the [downloads/](downloads) folder, where more information and software usage can be found.

Note that LHAPDF grids can also be found from [LHAPDF distribution](https://lhapdf.hepforge.org/).
